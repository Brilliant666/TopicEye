# README 来源角色与已保存 Find 时间修正

## 范围

修正公开 README 中赞助广告、免责声明和明确属于其他版本的功能被当作
项目介绍/定位的选择错误；区分定位的本地语义拒绝与 Provider 故障；
已保存 Find 展示原运行时间，不再声称正在实时检索。
不修改模型、日预算、排序、日程或历史 Find 结果，不手动补跑。

## 实现

- 在原资料提取与所有来源模式的定位候选校验中区分正文和广告/声明，
  允许真实描述保留合法限制，不按仓库名称匹配。
- 已有完整缓存仍先严格验证 envelope、身份、证据、引用及摘要；之后仅
  生成读取投影，使用原证据中的中文项目正文，省略误归属的其他版本功能。
  无可靠替代介绍时省略可选资料，榜单事实不受影响。
- 资料投影保留原文件、生成时间、来源版本和证据；清洗后的差异仍去重。
- 定位语义拒绝使用有限规则分类与脱敏诊断；未知原因保持未知。
  丢失的历史模型响应不声称已经恢复或确定了其准确原因。
- Find 用服务器已有 createdAt/finishedAt 标明北京时间，区分原运行生成、
  原运行缓存复用与当前回读；不改变提交、鉴权或预算路径。

## 零调用验证

先以通用资料复现，再进行回归；覆盖广告/免责声明、真实合法限制、
其他版本边界、已有资料投影、原证据/日期不变、重复读取幂等、
无替代正文的局部降级和三个定位来源模式。

定位失败包括实际 collector 接线、诊断持久化及独立进程禁网回放；
Find 测试包含已保存结果、无效时间降级、刷新与手机布局。

生产公开仓库的完整原始 envelope 在仓库外按原字节保存，以原严格解析
和正常读取投影离线回放通过：广告/声明不再占据主文案，其他版本功能
被省略，资料为 partial，文件、日期、证据与重复读取保持不变。
原资料及私有 Find 正文不提交 Git。

必要 CI、正式发布与真实桌面/手机验收分别记录，不以模拟测试代替发布。
本次研发/验收新增 Provider 调用为 0；不制造自然日程成功样本。
