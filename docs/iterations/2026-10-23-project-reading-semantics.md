# 项目分类与阅读语义修正

基线 main `37c699e`（PR #79）。本轮不修改排序、日程、预算、历史处理数量或生产数据，不发模型请求。

- 分类按项目主体和用途语句归属，不把构建 SDK、安装电脑或训练数据集当成交付类型/运行平台。无法归属时留空；不使用仓库名称特例。
- 不再从能力列表强制抽两项作为差异。旧资料仅删除去除已知伪包装后完全相同的能力文本；真实比较限定、否定和限制保留。差异字段允许为空，身份、引用、内容和其余质量校验不变。
- 已保存资料在原始完整性与历史修订验证后生成只读展示投影；原文件、生成时间、证据和缓存身份不改。原始版本精确回查及已有项目解读缓存仍使用原输入；真实内容修订仍影响分析身份。
- 入门链接稳定优先安装、使用与文档，资源文件后置但不删除。页面说明资料已保存而非功能已运行验证，明确 README blob SHA 不是仓库提交 SHA。

相关验证包含分类归属、真实差异保留、旧修订兼容、损坏资料拒绝、Today/历史/详情共用、原始分析缓存命中、读取零生成及前端措辞。模拟回归、已有生产缓存离线回放、最终 CI 与上线浏览器验收分别记录，不将模拟测试称为生产验收。
